# Open Deck 0.10.2 — 실기기 설정 검증

Galaxy Tab S7(`SM-T870`)과 운영 Mac의 네이티브 앱에서 일반 설정 29개와 이름의 양방향 반영·재시작 유지를 확인했다. 보안 설정 1개는 별도 Mac WKWebView 편집기·합성 호스트·실기기 검증 APK의 격리 환경에서 확인했다. 원래 설정 복원, 실기기 설치 파일 대조, 연결 정리와 최종 읽기 전용 보존 검사까지 통과했다.

## 환경과 범위

- 실기기: Galaxy Tab S7, 기존 `0.10.0`에서 `0.10.2`·build `18`로 업데이트.
- 소스: [452b0cf](https://github.com/Yaklede/open-deck/commit/452b0cfbaa0f22dc93fd23306c08f501f326ae9c).
- 일반 설정은 실제 Mac 설정 화면과 실기기 Android 설정 화면에서 변경한다. API 결과는 화면 비교와 별도의 저장·전달 증거로 구분한다.
- 이번 작업은 이미 배포된 `0.10.2`의 실기기 검증이다. 소스와 배포 파일을 변경하지 않으므로 `v0.10.2` 릴리즈를 재발행하지 않는다.

| 분류 | 범위 | 이번 검사에서의 취급 |
| --- | ---: | --- |
| 공유 기기 설정 | 30개 | 일반 설정 29개와 보안 설정 `allowInsecureWifi` 1개를 구분 |
| 기기 이름 | 1개 | 설정 map과 별도로 양방향 저장·표시 확인 |
| Mac 전용 preferences | 34개 | Android와 동기화할 대상이 아님. 검증 전후 무변경 비교 대상 |
| Android 전용 연결 설정 | 연결 방식·Wi-Fi 주소 목록 | 기기 로컬 설정. 공유 30개 항목에 포함하지 않음 |
| Android의 기억하는 화면 상태 | 마지막 페이지·Grafana 프로젝트 | 공유 설정값 검사와 별도 |

Mac 편집기 자체의 언어·테마·UI 크기와 태블릿별 언어·테마·글자 크기는 서로 다른 설정이다. 전체 필드와 저장 위치는 [설정 인벤토리](evidence/0.10.2/full-settings-inventory.json)에 기록했다.

A·B의 운영 앱에서는 보안 설정이 계속 꺼져 있었다. 별도 격리 검사에서는 Mac WKWebView 컨트롤에서 켠 값의 실기기 반영·실기기 재시작 유지, 실기기에서 끈 값의 Mac 컨트롤 반영, 호스트·Android·검증 Mac 창 재시작 후 꺼짐 유지를 확인했다. 이 보안 검사는 배포된 Mac 앱 셸 자체가 아닌 같은 설정 UI를 사용하는 별도 네이티브 WKWebView에서 수행했다. USB로 설정을 전달했으며 실제 사설 Wi-Fi LAN의 평문 HTTP 연결을 시험한 결과는 아니다.

## 원상복구와 최종 보존 확인

대상 태블릿의 원래 이름과 원래 저장되어 있던 6개 설정을 복원했다. 나머지 항목은 공유 기본값을 적용하여 기존의 **유효 설정 30개**로 되돌렸다. 저장 구조가 명시적 30개 값으로 바뀌는 것은 이전 사용 동작을 복원하는 것과 구분한다.

복원 직후 세 번의 읽기에서 일치를 확인했고, 운영 덱과 Mac preferences, 다른 페어링 기기 3대의 이름·설정이 기준 상태와 같으며 대상 페어링도 유지됨을 확인했다. 실기기 앱의 `0.10.0 → 0.10.2` 업데이트와 로컬 연결 방식의 `wifi-only → auto` 변경은 의도한 결과다. 연결 방식은 공유 설정 API에 포함되지 않으므로 실기기 화면에서 복원 직후와 앱 재시작 후 각각 확인했다. 운영 앱의 비암호화 Wi-Fi 허용은 꺼진 상태다.

검증용 APK가 현재 Android 사용자에서 제거되었고, 임시 `18840` ADB reverse가 없으며 합성 호스트가 종료되었음을 확인했다. 마지막 실기기 앱 재시작 후 운영 연결이 다시 온라인 상태가 됐고, 최종 읽기 전용 보존 검사의 모든 항목도 통과했다.

## 검증의 한계

이 검사는 설정 컨트롤의 표시값, 저장, 양방향 전달과 앱 재시작 복원을 확인한다. 실제 진동 강도, 패널 밝기의 물리적 수치, 출력 음량, 모든 업무 알림의 도착을 측정한 결과가 아니다. macOS·Android 운영체제 재부팅이나 모든 설정 조합의 동작도 검사 범위에 포함하지 않는다.

공개 증거에는 비식별화한 판정과 필요한 설정값만 남긴다. 비밀값, 기기 UUID, 원래 기기 이름, 사용자 프로필·페이지 이름과 업무 내용은 포함하지 않는다. 검증 내용은 릴리즈 노트와 분리한다.
