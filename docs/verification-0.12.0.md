# Open Deck 0.12.0 그래프 확대·이동 에뮬레이터 검증

Android API 34·2560×1600 에뮬레이터의 네이티브 Open Deck **0.12.0 / build 21**에서 Grafana 그래프 8개의 확대·이동·값 조회·전체 구간 복귀를 확인했다. **8개 그래프 × 4개 동작, 32/32개 판정**이 통과했고, 확대 상태에서 선택한 시각·값을 합성 원본 샘플과 대조한 **8/8개 검사**도 통과했다.

검증 앱의 소스 커밋은 `c2547bf5dc5b12d3dd654efc9504ca5bbfa9b24a`다. [공개 검증 JSON](evidence/0.12.0-emulator.json)에 판정·범위·원본 172개 파일의 SHA-256을 기록했다. 추가 확대 구간 검사 7/7개와 최종 GitHub 설치 파일 확인도 완료했다.

## 검증 환경과 범위

기존 운영 Grafana가 HTTP 403을 반환하여, 운영 권한·VPN을 변경하지 않고 격리한 표준 Open Deck 호스트를 사용했다. 이 호스트는 dashboard/query 요청에 메모리에서 생성한 응답만 공급한다. 실제 생성 시각이 있는 합성 샘플 60개를 60초 간격으로 제공하고 30초마다 다시 수집하며, 표준 인증·페어링·SSE 경로를 유지한다. 외부 Grafana 요청이나 키체인 조회는 수행하지 않는다.

격리 호스트 프로세스는 `9bee3390bc383075f6eff2b7163b3152c05116bf` 시점에 시작했다. 최종 Android 앱 소스와 fixture 프로세스 시작 시점을 구분해서 기록한다. 모니터 페이지에는 서버·DB Grafana 위젯만 배치했다. **실기기·실제 Wi-Fi 전송·운영 실시간 데이터 검증은 이번 결과에 포함하지 않는다.** 원본 샘플 시각이 없는 내 Mac의 별도 로컬 이력 그래프도 제외한다.

각 그래프에서 전체 약 59분 구간이 약 17분으로 줄어들었고, 한 손가락 이동으로 약 5분 과거 구간을 표시했다. 확대 상태의 탭은 선택한 시각과 값을 표시하며 합성 원본 샘플과 일치했다. 반대 방향 핀치 후 전체 구간으로 복귀했다. 구간 길이는 저장된 결과 파일의 분 단위 판정값을 기준으로 기록했다.

## 시각 검토와 환경 정리

독립 검토자는 시스템 그래프 6장과 DB QPS·메모리 그래프 6장, 총 12장을 확인했다. 이 결과를 모든 캡처의 시각 검토로 확대하지 않는다. 검증 후 임시 fixture 호스트와 이번 작업용 에뮬레이터를 종료했고, 다른 작업의 에뮬레이터는 유지했다.

## 설정 보존과 최종 릴리즈

비공개 기준 상태와 비교해 운영 덱, 페어링 기기 ID, 기기별 설정이 모두 같았다. 에뮬레이터에 설치된 APK의 SHA-256도 배포 APK와 일치했다.

[GitHub v0.12.0 릴리즈](https://github.com/Yaklede/open-deck/releases/tag/v0.12.0)는 정식 최신 릴리즈로 게시됐다. 태그·소스 커밋은 `c2547bf5dc5b12d3dd654efc9504ca5bbfa9b24a`로 일치한다. APK·Mac ZIP·SHA256SUMS의 GitHub digest와 재다운로드 SHA-256이 모두 일치했고, Mac ZIP CRC 및 내장 build-info도 통과했다.

공개 APK의 버전은 **0.12.0 / code 21**이다. 서명 검증을 통과했으며 기존 서명자 SHA-256 `15cfc6762d9b063abd2ce5b8cd665757f1e30b03707b921abb4619ff38aeba4a`를 유지했다. `SHA256SUMS.txt` 자체의 SHA-256은 `7746d0c2e08ad8d83e51df1c963e54cdaedc1a2cbbd7be50f14328ea5f76dd8b`다.

## 공개 자료의 범위

공개 JSON에는 판정·검증 범위·빌드 정보·SHA-256을 기록했다. 페어링 화면, PIN·관리자 키·runtime 파일, 운영 설정, 기기 식별자, 원본 PNG/XML과 시계열 배열은 공개하지 않는다. 합성 데이터 검증 결과를 실제 운영 지표 정확성이나 연결 장애 복구의 증거로 사용하지 않는다.
