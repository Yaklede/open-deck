# Open Deck 0.10.2 — 전체 설정 동기화 검증

공유 설정 30개와 기기 이름의 양방향 반영·재시작 유지 검증을 완료했다. 비보안 설정 29개와 이름은 네이티브 Mac 앱·Android 에뮬레이터에서 확인했고, 보안 설정 1개는 별도 검증 앱·합성 호스트로 분리했다. Mac에서 바꾼 값의 적용·재시작 비교는 120건 모두 일치했다. Android에서 바꾼 값의 검증 중 발견한 오프라인 시작 페이지 이름 표시 오류는 수정 후 90건 재검증에서 모두 통과했다.

## 이번 소스에서 확인한 보완

- Mac의 태블릿별 설정에 언어와 암호화하지 않는 Wi-Fi 허용 항목을 추가해 공유 30개 필드의 양쪽 컨트롤을 모두 갖췄다. 평문 연결은 기본 꺼짐이며 토큰·데이터 암호화가 해제된다는 안내를 표시한다.
- Android 밝기와 화면 보호 대기시간은 프리셋 외에 정수를 직접 입력할 수 있다. 글자 크기·진동 길이·화면 보호 밝기는 1단위 조절로 서버가 허용하는 정수 범위를 선택할 수 있다.
- 프로필의 시작 페이지, 마지막 페이지 기억, 이름이 같은 프로필·페이지 선택 경로를 보완했다. 잘못된 값이나 묶음 요청을 거부할 때 유효한 필드와 기기 메타데이터를 일부만 저장하지 않도록 검사한다.
- 오프라인 재실행 시 시작 페이지 이름 대신 ID가 표시되던 오류를 수정했다. 마지막 연결에서 받은 프로필·페이지 이름 목록을 기기 로컬에 저장하고 설정을 열기 전에 복원한다. 저장 허용 항목은 `defaultProfileId`, 프로필의 `id/name/defaultPageId/pageIds`, 페이지의 `id/name`으로 한정한다. 액션·URL·인증 정보·실시간 업무 데이터는 이 캐시에 복사하지 않으며 페어링 초기화 시 삭제한다.

위 보완은 소스와 자동 검사로 확인했다. 실제 앱 화면에서 확인한 양방향 반영·재시작 결과는 아래 필드별 표와 공개 실행 기록에 구분해 기록한다.

## 전체 필드의 네이티브 앱 검증표

시나리오 A는 Mac에서 값을 바꾼 뒤 양쪽 열린 설정 화면에서 확인하고 두 앱을 종료·재실행하는 흐름이다. [Mac → 에뮬레이터 실행 기록](evidence/0.10.2/mac-to-emulator-runtime.json)에서 비보안 설정 29개와 이름의 적용 직후·재시작 후 Mac·Android 값 **120건이 모두 일치**했다. 원본 캡처의 해시와 값별 판정은 공개 기록에 포함하고 사용자 프로필·페이지 이름과 기기 이름은 가렸다.

시나리오 B는 Android에서 값을 바꿔 Mac에 반영하고, 두 앱을 종료한 다음 Mac이 중단된 상태에서 Android를 재시작하고 Mac을 복귀시키는 흐름이다. [Android → Mac 실행 기록](evidence/0.10.2/emulator-to-mac-runtime.json)의 최초 비교는 **150건 중 149건 일치**했고, 시작 페이지 이름 표시 1건이 달랐다. 해당 페이지 ID와 저장값은 유지됐지만 호스트가 없는 동안 이름 대신 ID를 표시했다. 최종 소스 `452b0cf`에서 이름 캐시를 수정한 뒤 Android 오프라인 재시작 30건, Mac 복귀 후 호스트 값 30건, 실제 Mac 설정 UI 30건을 다시 대조해 **90건 모두 통과**했다. 최초 실패를 지우지 않고 같은 증거 파일의 `finalRetest`에 수정 후 결과를 덧붙였다. 표의 런타임 결과에는 API·모델 검사 결과를 대신 넣지 않았다.

Android에서 끈 뒤 호스트의 `false` 확인은 실행 담당자의 API assertion으로 구분해 기록했다. Mac 보안 컨트롤 자체는 기존 합성 편집기 30개 컨트롤 시험에서 확인했으며 이 런타임 기록은 네이티브 Mac에서 보안 허용을 누른 시험이 아니다. 보안 항목에는 비보안 설정의 오프라인 시작 시나리오 B를 그대로 적용하지 않았다.

재시작 비교는 설정값과 표시된 컨트롤을 함께 대조했다. 프로필 변경이 시작 페이지를 초기화하는 등 의도된 결합 동작은 예상값에 반영했다. 저장하지 않은 Mac 폼 초안은 앱 종료 후 유지되는 저장값으로 간주하지 않았다.

## 연결·오프라인 검증 범위

| 시나리오 | 상태 | 기록 범위 |

같은 필드의 충돌은 서버 적용 순서가 기준이다. 오프라인 편집은 뒤늦게 서버에 전달될 수 있으며 서로 다른 기기의 편집 시각을 비교하는 병합 기능은 아니다. 다른 필드의 부분 변경 보존과 지연된 응답·재편집은 자동 회귀 검사에서 별도로 확인한다.

이번 에뮬레이터 검증은 설정 컨트롤의 값, 저장, 양방향 전달과 재시작 복원을 입증한다. 실제 하드웨어의 진동 강도·패널 밝기·출력 음량이나 외부 업무 알림 도착을 측정한 결과는 아니다. 운영체제 재부팅이나 모든 설정 조합의 화면 효과 측정도 이 표의 완료 조건에 포함하지 않는다.

## 검증 후 원상복구

[원상복구 기록](evidence/0.10.2/restoration.json)에서 시험한 에뮬레이터의 이름과 유효 설정 30개를 원래 값으로 복원했고, 세 번의 읽기에서 일치를 확인했다. 해당 기기의 페어링을 유지했으며 운영 덱·Mac preferences와 다른 페어링 기기는 변경되지 않았다. 앱 버전과 마지막 연결 시각은 읽기 결과 비교에서 제외한 메타데이터다.

## 릴리즈·설치 파일 대조

[v0.10.2 릴리즈](https://github.com/Yaklede/open-deck/releases/tag/v0.10.2)를 게시했고 최신 릴리즈 및 태그의 소스 `452b0cf` 일치를 확인했다. [배포 검증 기록](evidence/0.10.2/release-verification.json)에 공개 주소에서 다시 받은 macOS ZIP·Android APK·SHA256SUMS 3개 파일이 로컬 빌드 및 GitHub digest와 모두 일치하는 결과를 기록했다.

[설치 파일 대조 기록](evidence/0.10.2/installed-artifacts.json)에서 설치된 Mac 앱은 `0.10.2`·build `18`·소스 `452b0cf`이며, 에뮬레이터에 설치된 운영 APK의 SHA-256도 공개 APK와 일치했다. 보안 시험용 앱과 임시 ADB reverse는 제거했다.

공개 증거는 필드 값과 비식별화한 비교 결과만 사용한다. 사용자 덱, 일정·업무 내용, 실제 기기 식별자, 암호·토큰·복구 키와 비공개 파일 경로는 포함하지 않는다. 릴리즈 노트에는 사용자에게 달라지는 동작과 설치 안내만 기록하고 이 검증 과정은 넣지 않는다.
